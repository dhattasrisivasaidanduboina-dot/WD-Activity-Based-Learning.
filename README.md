## 🚀 Projects Summary

### 1. Case 1: Personal Portfolio Website (`case1.html` & `case1.css`)
* **Objective:** Build a clean personal resume/portfolio webpage.
* **Key Features:**
  * Header masthead with student title.
  * Internal navigation links to section anchors (`#about`, `#education`, `#skills`, `#projects`, `#contact`).
  * Styled skill badges and structured project blocks.
* **Color Palette:** Deep navy header (`#172554`), vibrant blue highlights (`#2563eb`), and light blue badge backgrounds (`#dbeafe`).

### 2. Case 9: Sweet Treats Bakery Website (`case9.html` & `case9.css`)
* **Objective:** Design an attractive e-commerce web storefront for a bakery.
* **Key Features:**
  * Responsive menu card layout generated with CSS Flexbox (`flex-wrap: wrap`).
  * High-quality food product cards featuring image displays, description, bold price badges, and order buttons.
  * Special offers banner for promotional deals.
* **Color Palette:** Warm brown (`#713f32`), soft peach background (`#fff8f0`), and vibrant green price highlights (`#218044`).

### 3. Case 20: Royal Cafe & Restaurant (`case20.html` & `case20.css`)
* **Objective:** Develop a multi-section restaurant web application with table reservation capability.
* **Key Features:**
  * Comprehensive food and beverage menu gallery.
  * Interactive HTML reservation form including text fields, phone numbers, date selectors, dropdown choices, and special request textareas.
  * Customer reviews section with star-rating badges.
* **Color Palette:** Deep coffee brown header (`#512b1b`), caramel navigation (`#d99a45`), and warm cream container fills (`#fff4e5`).

## 🛠️ How to Run the Projects

1. Clone or download this repository to your local computer.
2. Ensure all `.html` and `.css` files reside in the same directory as referenced in the code files.
3. Open any of the `.html` files (`case1.html`, `case9.html`, `case20.html`) directly in any web browser (Google Chrome, Microsoft Edge, Firefox).
4. Alternatively, launch using the **Live Server** extension in Visual Studio Code for local hot-reloading.
